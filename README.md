# DevSolutions - Soluciones Empresariales con IA y Digitalización

Plataforma de presentación para **DevSolutions**, especializada en soluciones empresariales con inteligencia artificial y digitalización.

## 📋 Características

- ✅ **Landing Page Profesional** - Diseñada con Tailwind CSS
- ✅ **Responsive** - Se adapta perfectamente a móviles, tablets y desktop
- ✅ **Rápida y Optimizada** - Carga instantánea sin dependencias pesadas
- ✅ **Iconos Lucide** - Iconografía moderna y limpia
- ✅ **Sin Verificación** - Acceso directo sin formularios de validación

## 🚀 Secciones

1. **Inicio (Hero)** - Presentación principal con llamado a la acción
2. **Servicios** - 6 servicios principales:
   - Desarrollo Web
   - Aplicaciones a Medida
   - Planificación y Arquitectura
   - Integración de Sistemas
   - Optimización (Performance)
   - Soporte y Mantenimiento

3. **Nosotros** - Información sobre el equipo y valores
4. **Contacto** - Múltiples formas de contacto (WhatsApp, Email, Facebook)
5. **Footer** - Enlaces rápidos y redes sociales

## 🛠 Tecnologías

- **HTML5** - Estructura semántica
- **Tailwind CSS** - Framework de utilidades CSS
- **Lucide Icons** - Librería de iconos SVG
- **JavaScript Vanilla** - Interactividad sin dependencias

## 📱 Responsive Design

Optimizado para:
- 📱 Dispositivos móviles (320px+)
- 📱 Tablets (768px+)
- 💻 Desktop (1024px+)

## 🌐 Deploy en Vercel

Desplegado automáticamente con Vercel para máxima velocidad y disponibilidad.
